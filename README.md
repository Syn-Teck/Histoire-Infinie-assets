# Histoire Infinie — Assets

Dépôt public d’assets visuels pour la campagne **Histoire Infinie / Shadow RPG**.

## Objectif
Ce dépôt sert de pont persistant entre les images générées, la bibliothèque d’assets et Notion.

## Structure
- `assets/characters/` — portraits, fiches et variantes par personnage
- `assets/scenes/` — scènes d’équipe, combats, interrogatoires et moments narratifs
- `assets/dungeons/` — environnements et salles
- `assets/creatures/` — monstres, familiers et créatures
- `assets/items/` — objets, artefacts et loot
- `manifest/images.json` — registre machine-readable des assets

## Règles
- Les images sont conservées; une nouvelle variante n’écrase pas l’ancienne.
- Le canon écrit prime sur les détails accidentels d’une illustration.
- Les fichiers publics de ce dépôt peuvent être utilisés comme source RAW pour Notion.
