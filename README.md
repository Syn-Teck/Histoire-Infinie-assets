# Histoire Infinie — Assets

Dépôt public d’assets visuels pour les campagnes **Histoire Infinie**.

## Campagnes actives

### Alpha — Histoire Infinie — Chroniques de Shadow
Chemin :
`alpha/Histoire-Infinie-Chroniques-de-Shadow/`

Cette section contient les assets visuels de la campagne Shadow actuellement jouée et de son engine en développement.

## Objectif
Ce dépôt sert de pont persistant entre :
- les images générées;
- la Library d’assets;
- GitHub;
- Notion.

## Structure Alpha
- `characters/` — portraits, fiches et variantes par personnage
- `scenes/` — scènes d’équipe, combats, interrogatoires et moments narratifs
- `dungeons/` — environnements et salles
- `creatures/` — monstres, familiers et créatures
- `items/` — objets, artefacts et loot
- `manifest/images.json` — registre machine-readable des assets de la campagne

## Règles
- Les images sont conservées; une nouvelle variante n’écrase pas l’ancienne.
- Le canon écrit et les fiches mécaniques priment sur les détails accidentels d’une illustration.
- Les fichiers publics de ce dépôt peuvent être utilisés comme source RAW pour Notion.
- Les nouvelles images de la campagne Shadow doivent être classées dans la section Alpha jusqu’à promotion vers une version ultérieure.
